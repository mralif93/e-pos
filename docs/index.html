Setup in Minutes

Get your environment up and running with a few simple commands.

# Clone & Install
git clone https://github.com/mralif93/e-pos.git
cd e-pos
composer install && npm install

# Setup Environment
cp .env.example .env
php artisan key:generate

# Database initialization
touch database/database.sqlite
php artisan migrate --seed

# Build & Serve
npm run build
php artisan serve
